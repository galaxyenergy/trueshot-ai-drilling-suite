# TrueShot AI Drilling Intelligence Suite

A collection of AI-powered drilling applications focused on:

- Predictive Maintenance
- Automated Reporting
- Directional Drilling Analytics
- ROP Optimization
- Anti-Collision Monitoring

## Modules

### MWD Predictive Maintenance
Predict tool failures and identify root causes.

### Automated Reporting
Generate AI-powered MWD and DD reports.

### Directional Drilling Analytics
Monitor drilling performance and well trajectory.

### ROP Optimization
Recommend drilling parameters and predict performance.

### Anti-Collision Monitoring
Assess well separation and collision risk.

## Technologies

- Python
- Streamlit
- Scikit-Learn
- Pandas
- NumPy
- Matplotlib
- ReportLab
